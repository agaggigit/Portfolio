# Aga's Portfolio

A short introduction to who I am, what I'm interested in, and my experience so far.

![Hero section](docs/hero.png)

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS v4
- GSAP
- Lenis
- TypeScript

## Directory Structure

```
app/         layout, page, global styles, metadata
components/  page sections (Hero, About, Projects, Experience, Footer)
data/        site content — profile, projects, experience
public/      images and CV
```

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
